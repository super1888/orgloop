# 设计审查结论

审查对象：OrgLoop设计基线。审查与修正用于降低可识别的设计缺陷，不承诺没有未知问题，更不代表应用已经实现或生产效果成立。下列为正式发现与处理结论，原始工作讨论不进入公开仓库。

## 第1轮：跨作者需求、数据与契约闭合

审阅者未参与需求、架构和API编写。对照需求/治理/数据模型走查契约回读、授权、纠错和承接。固定契约SHA256：`e770b561dd4cade1abb4cf44767a49a21f7ef43eac2994a04dfe2be16a8150af`。

| 发现 | 后果 | 设计处理 |
|---|---|---|
| R1-01/P1 授权者不能回读完整动作与授权条件 | 刷新或换审批人后，无法核实具体执行内容 | Action返回目标/参数/摘要/来源，Authorization返回委托主体/决定/预算/条件；执行绑定内容并复核 |
| R1-02/P1 能力修订、撤下、共享与经验续版缺入口 | 贡献者权益和经验维护无法通过接口完成 | 增加能力GET/PATCH/撤下、经验/Skill续版与确认、用途限制申请和处理 |
| R1-03/P1 纠错和结果只有提交没有处理出口 | accepted/verified等状态无法可靠达成 | 增加纠错读取/处理、反馈回复、结果核实/修订，并保留来源实际生效范围 |
| R1-04/P1 来源、方法、决定和结果回读不足 | 持久工作空间只能依赖旧对话和浏览器缓存 | 增加来源历史版本、受控附件、决定/结果GET，补齐Skill内容与条件 |
| R1-05/P2 负责人和参与者交接未定义 | 通知转交可能被当作已承接 | 增加成员访问管理、待接受的负责人交接和并发核实；原负责人保持至有效接受 |

以上已在设计契约与[API说明](API.md)修正，仍需实现后的运行与权限验证。OpenAPI规范验证通过只证明结构有效。

## 第2轮：需求场景驱动的冲突与失败推演

审阅者编写需求与合成场景，但未编写被审的API、架构、数据和runtime。按SCN-001至SCN-026核对正常、拒绝、未知、冲突、并发、撤销与恢复。固定契约SHA256：`728148252d1803c2813e443778022a8abdbef6417becc080305d9e46f76f4de0`。

| 发现 | 后果 | 设计处理 |
|---|---|---|
| R2-01/P1 支持请求回读缺期限、上下文与接受条件 | 无法重建实际承诺 | SupportRequest补原始需求、期限、资源线索、条件和回应引用 |
| R2-02/P1 申诉/用途限制回读缺原诉求 | 受理者无法依据原内容核查 | Feedback/UsageRestriction保留请求、证据、申请理由与处理理由，区分申请和生效 |
| R2-03/P1 等待后worker执行身份不明确 | 可能继承新owner或服务账号的更大权限 | Run持久绑定原主体/委托/epoch/政策/边界，每步按当前资格复核；交接不自动迁移权限 |
| R2-04/P2 异步撤权没有恢复查询 | 刷新或清理失败后无法跟踪 | 返回job_id并增加撤权GET；同步阻断和异步清理分别记录 |
| R2-05/P2 评测读取缺基线、版本、报告和成本 | 发布审阅无法核实迁移和退化 | EvaluationRun补基线、suite/数据/runtime版本、受控报告、成本、限制及独立审阅；Run补预算与步骤 |
| R2-06/P2 授权绑定混用内容与生命周期版本 | 合法状态变化使授权失效，或恢复时绕过校验 | 不可变proposal_version/digest与生命周期version/ETag分离；新内容重新授权，状态变化不改变内容授权 |

以上已在契约、[数据模型](DATA_MODEL.md)、[运行机制](RUNTIME.md)、[架构](ARCHITECTURE.md)和API修正。补充结构正反例不替代真实恢复/授权测试。

## 第3轮：最终整合审查

待完整材料的静态检查及独立整合审查。审查将包含：显式用户目标、全业务范围、前后端分离、跨文档一致、公开内容、价格算例及验证工具能否识别人为破坏。完成后在此补充对象、发现、修正和剩余限制。

## 证据边界

- 三类独立性分别是跨作者审查、需求场景推演与最终整合核对；多个Agent意见一致本身不是正确性证明。
- 所有SCN当前仅为公开合成验收定义，未运行应用。真实接口、数据库RLS、OIDC、前后端交互、恢复、模型迁移和组织收益均未验证。
- 所有组织政策仍待相应责任方确认；当前文件不授予生产权限或采购许可。
- 最终可重复命令与运行状态见[VERIFICATION.md](VERIFICATION.md)，价格来源和限制见[SOURCES.md](SOURCES.md)及[COSTS.md](COSTS.md)。
