# 威胁模型与验证边界

状态：设计审查基线，2026-11-14。当前尚未实现应用，以下控制均为拟实现、待运行验证；静态文档和 OpenAPI 检查不能证明威胁已经消除。

范围承接 [需求](REQUIREMENTS.md)、[架构](ARCHITECTURE.md)、[数据模型](DATA_MODEL.md)、[运行机制](RUNTIME.md) 与 [治理](GOVERNANCE.md)。执行证据统一进入 [验证](VERIFICATION.md)，正式审查结论进入 [审阅](REVIEW.md)。

## 1. 需要保护的内容

- 成员的身份、访问范围、委托与纠错权；人物资料、关系存在性和经批准共享的经验用途。
- 业务记录、附件、来源版本、权限、派生索引、摘要、缓存和经验。
- 事项目标、决定、承接、预算、动作、回执、真实结果及审计完整性。
- 模型、工具、连接器和 Skill 的版本与执行权限；未见评测和发布结论的可信度。
- 专家时间与组织资源，以及成员主动提出问题、拒绝不适用请求和申诉的空间。

能力强或拥有平台运维权限不意味着可读取所有资料、替他人承诺、修改评价规则或征用高层资源。企业政策以 [DECISIONS.md](DECISIONS.md) 中的确认状态为准。

## 2. 信任边界

| 边界 | 信任规则 |
| --- | --- |
| 浏览器 → API | 会话、CSRF、输入、当前成员资格与资源权限在后端检查；UI 不作最终授权 |
| API/worker → 数据库与对象存储 | 受限运行账号、事务内组织上下文、细粒度应用授权、受控下载 |
| 来源资料 → 模型 | 全部作为不可信内容；来源文字不能成为授权或系统指令 |
| 模型 → 工具/人员请求 | 模型提出建议；服务端验证当前身份、动作、参数、授权、预算与版本 |
| 内部动作 → 外部系统 | 依赖连接器能力和真实回执，不假设远端支持幂等或回滚 |
| 经历 → 经验/Skill → 发布 | 用途、来源、独立验证和适用范围逐层检查，不自动扩大权限 |
| 内部环境 → 公共仓库/外部模型 | 只按批准用途输出；公开代码与企业实际数据、凭据和评测资料隔离 |

潜在错误或攻击可以来自外部资料、已登录成员、受损连接器、错误配置、模型输出或内部高权限操作者。设计不能只防匿名请求，也不能假设所有已认证输入都正确。

## 3. 具体威胁、控制与未来证据

### T-001 来源指令被当作权限或任务

**路径：** 一份文档、工单或连接器返回包含“忽略原任务、导出资料、发送消息”的诱导文字；Agent 将其当成指令调用具有真实能力的工具。

**控制：** 来源和系统指令分层；工具注册白名单；参数与资源引用校验；模型不接触凭据；所有调用经后端授权、出口与预算检查。来源不能注册新工具、改变网络目的范围或扩大委托。允许的检索仍应可用，不用“遇到可疑文字就停掉全部工作”替代细粒度控制。

**未来证据：** SCN-015/SCN-025 的诱导文本、工具调用记录、越权拒绝和正常检索对照；验证隐藏租户、私人原文与未经批准的消息均未被访问或发送。覆盖 REQ-002、REQ-005、REQ-014。

### T-002 租户或会话上下文串用

**路径：** 成员修改组织/资源 ID，重用事件游标或下载链接；连接池或 worker 继承了另一个租户上下文；缓存、命中数、错误或日志透露隐藏对象。

**控制：** 后端从会话推导身份与组织；复合键、应用权限与受限账号 RLS；组织上下文事务内设置并验证池化复用；检索、事件、引用、缓存及附件执行相同边界。幂等结果重放前也检查当前权限，不能成为读取旧敏感响应的旁路。

**未来证据：** 两个合成组织、相同名称对象及直接 API 请求；交换主体、游标、缓存和对象引用，覆盖 API/worker/下载/错误信息；非owner账号和正常访问对照。SCN-015/SCN-024，REQ-002、REQ-013、REQ-014。

### T-003 伪造委托或借高层称谓征用资源

**路径：** 请求文字声称“董事长同意”，关系记录显示某人认识高管，或 P0 标签被当成批准；支持提供者点了接受后，Agent 进一步发出未获授权的外部承诺。

**控制：** 身份、关系、支持承接和动作授权分开；授权记录绑定主体、对象、动作、负载、期限与资源边界，执行前重新核实；修改关键负载后重新检查。职级与紧急标签不自动授予决定权，管理员不能通过改配置自行取得经营资源。

**未来证据：** SCN-004/SCN-011/SCN-023，包括伪造文字、过期授权、不同真实权限、变更负载和正确预先委托的对照；应阻止越权，同时保留合法跨层级申请路径。REQ-003～REQ-006、REQ-014；POL-001～POL-003。

### T-004 来源撤权后派生资料继续泄露

**路径：** 原文不可见，但旧 embedding、摘要、缓存、历史回答、事件或附件 URL 仍可取出内容；模型已经在途使用已撤回资料继续行动。

**控制：** 来源版本和依赖图；当前访问入口先拒绝，再异步失效派生物；输出、分享和执行前复查；附件私有存储、短时下载授权；对在途请求和已分发内容按用途、保留与处置政策处理。合法扩展共享范围须形成经批准的新版本，自动去姓名不构成许可。

**未来证据：** SCN-014/SCN-018/SCN-025，覆盖索引延迟、旧会话、旧链接、重分享、缓存和未执行/已在途动作。记录既有分发无法完全收回的边界，不能只凭原文已删除声称无泄露。REQ-002、REQ-007～REQ-009、REQ-011、REQ-014；POL-008。

### T-005 外部未知结果造成重复副作用或伪造完成

**路径：** 建单或发送已成功，但响应丢失；worker 重启后直接重试；模型输出“完成”被当成回执；本地取消被当成远端撤销。

**控制：** 业务幂等标识、操作尝试、远端操作 ID 和真实回执；连接器声明幂等/查询/撤销能力；`outcome_unknown` 与确认失败分开；reconcile 可记录仍未决；租约/版本阻止旧worker覆盖当前状态。取消停止新增动作，核实在途结果后才处理补偿。

**未来证据：** SCN-012/SCN-013/SCN-018，对照模拟外部系统实际动作数量与内部状态，注入发送前后中断、响应丢失、租约到期和取消。REQ-004～REQ-007、REQ-014。不能用仅测本地状态机证明跨系统 exactly-once。

### T-006 Skill 或工具供应链扩大执行范围

**路径：** 已共享的 Skill 包含新工具、隐藏网络调用、代码或提示注入；更新版本借用旧授权；模型生成的调用参数访问任意数据或运行代码。

**控制：** Skill 不可变版本、来源和发布权限；首版仅受控指导/已登记工具组合；输入输出 schema、工具范围和依赖校验；发布与授权分开；更新后检查差异与回归。工具/连接器代码作为正常软件审阅和锁定依赖，模型不能在运行中安装包或修改执行器。

**未来证据：** SCN-018 加入改变工具集合、失效来源、恶意参数和旧版本缓存；确认未批准调用不可执行，正常发布版本仍可用。REQ-005、REQ-006、REQ-009、REQ-010、REQ-014；POL-003/POL-007。

### T-007 奉承、权力偏好与学习污染

**路径：** 用户或高层偏好被当成事实；点赞和任务关闭被当成成功；原作者的自评充当独立证据；公开案例被反复优化后当成未见泛化；错误经验越复用越像权威。

**控制：** 保存当时信息、判断、实际行动和结果；偏好、事实与结果分开；态度/展示职级配对与有效新证据对照；候选经验有来源、反例和适用范围；独立未见任务与回归、总成本及人工负担共同评估。训练/优化输入与正式保留评测隔离，允许结果未决和不同评议。真实权限不同的角色仍保留相应执行差异。

**未来证据：** SCN-017/SCN-019/SCN-020/SCN-021，固定事实与目标比较判断漂移，加入真实新证据检查合理更新；保留失败与退化。公开合成用例检查只能支持相应一致性，不能单独证明组织效果。REQ-007～REQ-010、REQ-014；POL-006/POL-007。

### T-008 无限制 loop、成本消耗与反复打扰

**路径：** Agent 重复无效调查或重试模型，未知费用记零；多个 run 争用同一额度；专家或高管拒绝后仍被跨渠道提醒；调用量被误当成贡献。

**控制：** 每事项单活动 run，原子预算预留与实际用量对账；步骤/时长/调用/打扰额度；没有新信息时等待或停止；拒绝和承诺范围进入上下文。收费能力无预算不执行；未知费用保留估计与未决，不能自行充值或购买资源。

**未来证据：** SCN-003/SCN-021/SCN-023，注入费用回执缺失、并行额度竞争、持续拒绝、模型限流与重复同错；核对总费用和实际消息次数，并测试获准的新请求仍能正常承接。REQ-001、REQ-004、REQ-006、REQ-010、REQ-014；POL-009。

### T-009 员工经验被超用途提取或形成黑箱评价

**路径：** 将工作资料的读取许可当成公开、训练或人事评价许可；过度概括某人的能力；拒绝共享被自动记为不合作；聚合日志形成隐蔽员工价值分。

**控制：** 明确用途和分享方式；个人经验可由本人参与或限定共享，不要求完整提取；提供确认、更正、申诉与影响追踪；记录贡献与维护投入；日志不采集按键、持续截图或用在线时长评价。知识访问、训练用途、评价与组织制度修改分开授权。

**未来证据：** SCN-016/SCN-017/SCN-025，不同共享范围、纠错、拒绝与申诉路径；检查后续匹配和派生内容改变且没有自动负面评级。REQ-003、REQ-007、REQ-008、REQ-011、REQ-014；POL-005/POL-008。

这些技术设计不能保证岗位或收益永远不变。组织对经验用途、维护时间、收益、工作调整和复核的承诺需由有权者决定并实际兑现，不能用“系统不会替代人”的文字替代。

### T-010 公共仓库、构建产物或日志泄露真实资料

**路径：** 复制真实对话或客户材料作为示例；凭据进入配置/截图/报错；前端构建嵌入集成密钥；真实内部评测和原始输出随 Git 发布。

**控制：** 公共内容仅通用设计、公开引用和明确的合成资料；环境变量样例只放无效占位；真实数据、密钥、环境和运行输出与 Git 隔离；前端无模型/集成凭据；提交前检查暂存路径、差异和必要的敏感模式。自动扫描不能证明完全无敏感信息，人工审阅保留。

**未来证据：** 本轮公开差异人工审查及文档静态检查；实现阶段检查前端构建、日志与配置，使用合成秘密诱饵验证不会进入公开内容。当前文档审查只覆盖当前产物，不证明未来环境安全。关联 REQ-011/REQ-014 和仓库 `AGENTS.md`。

### T-011 错误身份合并导致关系、资料或权限错配

**路径：** 同名、同号码或语义相似被自动合并；岗位变化被覆盖历史；误把某人的引荐能力、资料或授权交给另一个身份。

**控制：** 来源标识与实体映射保留依据；不确定合并作为候选；身份、岗位、历史接触与支持承诺分别记录；可拆分更正并检查受影响请求、资料和授权。任何身份合并都不能自动扩大资料访问或动作权限。

**未来证据：** SCN-002/SCN-007/SCN-025，包含同名对象、号码未变但岗位变化、错误合并后拆分和已创建请求的复查。REQ-002、REQ-003、REQ-005、REQ-007、REQ-014；POL-004。

## 4. 控制的实现与审查责任

| 责任范围 | 应提供的证据 |
| --- | --- |
| 身份/政策与 API 维护人 | 会话、CSRF、租户、委托、访问/执行分离和错误响应测试 |
| 数据/检索维护人 | 当前权限、来源依赖、缓存/附件失效、身份更正与查询隔离 |
| 工具/连接器维护人 | 副作用、幂等、回执、未知、取消、恢复和凭据范围 |
| Runtime/模型维护人 | 预算、单活动run、schema、诱导输入、判断依据和版本 |
| 经验维护人与独立评测者 | 用途、反例、新事项、回归、发布与撤回证据 |
| 组织授权与权益责任人 | 实际受理、取舍、贡献、更正、申诉和责任政策的确认与兑现 |

同一人可在初期兼任工程职责，重要变更仍需由未负责该修改者独立核对。意见一致只能说明审阅结果，不能替代运行证据；组织政策与法律/合同责任不由工程测试代为确认。

## 5. 当前限制与后续更新

- 尚未盘点真实系统、身份提供方、凭据、数据地域、处理合同或实际权限；不能宣称已覆盖具体企业环境的全部威胁。
- 已合法分发给人或外部模型的内容无法仅靠数据库撤销完全收回，接入前需明确用途、保留和处置边界。
- 经营结果受多因素影响，真实结果仍可能未知；反奉承检查和 holdout 也不能证明模型在所有情境可靠。
- 当前只定义控制和合成验证条件。每次增加连接器、工具、外部写能力、模型、Skill 或共享用途时，审查受影响的路径与回归，不将新风险静默继承为“已经通过”。

发现问题时限制受影响能力、停止新增副作用、保留必要证据和未知，再由相应责任人核实、更正、撤回并验证恢复。报告应说明版本、范围、已执行和未执行项，避免用“安全”“智能”两个标签代替证据。
