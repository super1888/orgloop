## 产品核心

每个事项拥有可持续的工作空间，保存目标、证据、未知、判断、协作承诺、行动和结果。Agent 能够调查、建议、调用已授权工具及申请人的支持；成员能够参与判断、接受或拒绝请求、纠正记录并共同学习。

全公司业务进入覆盖目录，按依赖逐步接入。能力与职位、历史接触与当前关系、提出建议与获得授权、接受请求与完成帮助、动作成功与业务成果分别记录。

经验带着来源、适用条件、反例和版本复用。新经验首先是候选，经过验证才扩大适用范围。模型权重训练、记忆、Skill 更新和工具策略改进是不同机制。

## 工程基线

- 独立前端：React、TypeScript、Vite，面向桌面端设计；独立构建。
- 独立后端：Python 3.12、FastAPI；API 与持久 worker 分进程，模块化单体。
- 数据：PostgreSQL 为主，必要的对象存储，全文检索及可选向量索引。
- 通信：版本化 REST API 与游标事件；同源反向代理下的后端会话和 CSRF 防护。
- 原系统保留各自权威记录；模型通过后端工具通道工作，不能持有业务系统密钥或直接操作数据库。

以上为推荐默认，取舍及修改条件见[决策记录](docs/DECISIONS.md)。目前没有 `apps/web`、`apps/api` 可启动应用；开发计划中的目录与命令会明确标为未来交付，不能当作已实现。

```sh

python3 -m unittest discover -s tests -v
```

检查范围是文档导航、需求追溯、契约结构、合成用例完整性及报价算例；它们不能替代实际应用、权限、恢复、模型行为和用户体验测试。完整入口与依赖见[开发文档](docs/DEVELOPMENT.md)。
